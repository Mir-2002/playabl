# Playabl

Playabl is a social listening app connected to Spotify. Every second of music you listen to earns you points — compete on the global leaderboard, maintain daily streaks, and share your stats with friends.

## Features

- **Points** — 1 second of verified listening = 1 point, tracked server-side via Spotify's recently-played API
- **Leaderboard** — global all-time rankings updated every ~3 minutes
- **Streaks** — daily listening streaks with a Duolingo-style streak calendar
- **Activity heatmap** — GitHub-style heatmap of your listening history
- **Now Playing** — live widget showing your current track
- **Friends** — send/accept friend requests via a shareable profile link
- **Public profiles** — share your stats; anyone can view and add you as a friend

## Stack

Next.js · Supabase (Auth, Postgres, Edge Functions, pg_cron) · Spotify API · Tailwind CSS · shadcn/ui
